# 2．構成と判断

| 論点       | 決定                                          | 理由                                                                  |

# 4．不具合の切り分け

| 観測                               | 原因・対応                                                                                                           | 確認                                                        |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Playwright試験成功後に停止待ち     | `pnpm dev`経由のサーバー停止に滞留。webServerをNodeによるローカルVite CLI直接起動へ変更しました。                    | 後続試験終了・所有プロセス残存0件。                         |
| 3D fixtureのLint失敗               | Three.Clock非推奨と、コールバック内代入を型検査が追跡できない条件。Timerと接触配列による判定へ変更しました。         | fixtureの型・Lint・checkが成功。                            |
| 存在しないリソースの負検査が誤成功 | ViteのSPA fallbackが`Accept: */*`にHTMLを200で返していました。負検査のAcceptをバイナリに限定しました。               | 実際の404を検出しE2Eが非0。                                 |
| 全suiteのhooks 3件がENOENT         | 既存mainでも再現。Gitの`~/.git-hooks`をliteralにfsで読んでいました。試験の取得コマンドだけに`--path`を追加しました。 | hooks単独3/3、全suite成功。Git設定・global hookの変更なし。 |
